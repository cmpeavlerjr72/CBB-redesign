# requirements-cloud.txt -- EXACT pins for the CBB engine seed-sweep cloud box.

# PYTHON 3.12 REQUIRED (built and parity-referenced on CPython 3.12.10, the
# same interpreter minor as the Windows .venv this was frozen from).
# Parity depends on VERSION IDENTITY, not "compatible" ranges: every adapter's
# joblib-pickled model (lightgbm boosters wrapped in a scikit-learn API) must
# unpickle into the SAME class implementation it was fit under, and the
# engine's per-possession draws run through numpy/scipy float paths, so a
# different minor of any of these can move a possession outcome and cascade
# the whole game. Do not relax a pin, do not add `--upgrade`, do not let pip
# resolve anything newer. If a pin cannot install on the target box, STOP and
# come back to the PM -- a substituted version invalidates the parity gate
# (docs/ops/aws_launch_chain.md).
#
# Load-bearing set (record these in any run log):
#   numpy 2.5.3   pandas 3.0.5   lightgbm 4.7.0   scikit-learn 1.9.0
#   scipy 1.18.1  joblib 1.6.0   pyarrow 25.0.1
# scikit-learn is load-bearing even though the engine never calls sklearn
# directly: cbb_sim.models.pace imports sklearn.linear_model at module level,
# and cbb_sim.models.clock imports pace, so the whole adapter stack fails to
# import without it. statsmodels is load-bearing for the same reason (pace.py
# imports statsmodels.api).
#
# Generated by `pip freeze` of the Windows .venv on 2026-09-10 (git
# db72e0d4b20754192c6bff2d1421fe3a4a893549). The repo's own editable install
# (`-e git+https://github.com/cmpeavlerjr72/CBB-redesign.git@...#egg=cbb_sim`)
# is REMOVED on purpose, same reasoning as cfb-props-sim's requirements-cloud:
# run_engine.py adds `src/` to sys.path itself
# (`sys.path.insert(0, ... / "src")`), so nothing needs the package installed,
# and an editable VCS pin would make the image build reach GitHub.
#

# hand-trimmed to a minimal set (duckdb/numba/llvmlite/matplotlib/ruff are
# pipeline/diagnostic tooling the sim path never imports) -- same choice
# cfb-props-sim made for pyreadr/patsy: a hand-trimmed list risks missing a
# transitive import that only breaks at runtime on the cloud box, and the
# extra ~300 MB of image size is cheaper than that failure mode.
