- A tip counts as real only if the feed says so (hoopR `time_valid`, CBBD not TBD) AND it is not exactly 00:00 America/New_York. - Chain: new stage `tips` after `schedule` (dry run writes nothing). New `--pass evening|morning`, default `evening`:
  - evening: run the evening before the slate (dry-run default clock 20:00 ET the day before; live runs use the real clock, schedule it for 20:00 ET). Slate default is the next game day. Every game tipping after the clock is simulated; a placeholder is later than any evening-before clock, so it can only err toward refusal after midnight ET. Placeholder games are flagged `tip_time_is_placeholder` in `slate.parquet`.
  - morning: the same-day re-publish (default clock 09:00 ET). Only games with a REAL tip still in the future are simulated; placeholders are refused with reason "placeholder tip time (not real)". Its run id has suffix `_morning`, so it writes a separate sim and a separate publication; GRADE still takes the earliest publication per game, so the evening line is the graded one.
  - `created_at < tipoff` (`guards.assert_created_before_tipoff`) still runs on every output row in both passes; the pass filters only choose which games are submitted to it.
