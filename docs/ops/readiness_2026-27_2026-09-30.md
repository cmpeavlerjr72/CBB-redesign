### 4b. Day 1 of a season: where as-of features start at 0.0 with no prior-season carry

Every table below groups by `(season, team|player)` (`expanding_asof` = `cumsum() - value`, or `shift(1).expanding()`), so the first game of
2027 sees zero history. Team-form features are league-centred, so no history is exactly 0.0 (`possession_outcome.py` line 48,
the fallback `fillna(0.0)` at line 461). Feature tables affected:

1. Possession outcome team form (14 base features off/def, `models/possession_outcome.py` `_expanding_asof`, lines 200-277) -- 0.0.
2. Rebound team and player as-of (`models/rebound.py` lines 281-320, 380; `n_prior_off/def` becomes 0).
3. FG make: team off/def as-of, shooter as-of (`models/fg_make.py` lines 440-470); has a `prior_season_make_c` / `has_prior_season_fg` carry for shooters only, team side no carry.
4. Free throw: `team_ft_asof`, `shooter_ft_asof` 0.0 with `prior_season_ft` for shooters only (`models/free_throw.py` lines 419-472).
5. Pace / clock style features: `own_style_*`, `opp_allowed_style_*` are NaN on day 1 (`shift(1).expanding().mean()`, `models/pace.py` lines 155-180), then filled by `_fillna` medians (train-time medians, not a carried prior). Clock `poss[c].fillna(0.0)` (`models/clock.py` line 567).
6. Usage and attribution player as-of (`models/usage.py`, `models/attribution.py` `PRIOR_KINDS` includes `prior_season`; the shrinkage prior exists, but the prior season tables must exist for 2026 and the join must run for 2027).
7. Rotation as-of (`models/rotation.py` `build_asof_player_features`, lines 264-318: `mpg_asof`, `share_asof`, `start_freq_asof`, `dnp_rate_asof`, `rotation_depth_asof`, all `shift(1)` cumulative) -- no prior-season carry.
8. Control-engine features (`control/features.py` lines 185-193) and engine arrays (`scripts/build_engine_inputs.py`, step 3: "falls back to ... exactly 0.0").
9. Own ridge ratings DO carry the prior season (ridge toward `prior_weight_eff = 0.8` x previous final fit,
   `ratings/own_ratings.py`), but there is no `own_ratings_2027.parquet` and no code path to produce it before game 1 (`build_all_seasons` is batch).
   KenPom: `data/processed/kenpom_snapshots.parquet`; the 2027 preseason folder is not on disk (`data/raw/kenpom` absent).

Day-1 consequence: team-form features are the league mean for every team, so early-season predictions collapse toward
the league average plus whatever the ratings provide (ratings carry the prior only if item 9 is done). The
Decision-7 V1/V2 prior blend is a modeling decision (bake-off), not an ops fix.
