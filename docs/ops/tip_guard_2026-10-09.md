# `created_at < tipoff` guard vs midnight placeholder tips (ops worker, 2026-10-09)

Ops / guard fix only; no model change. Parity v10 bit-identical; suite 776 passed, 1 skipped (+10 tests here).

## 1. The rule for a placeholder
CBBD stamps TBD games at 00:00 ET (`startTimeTbd`). hoopR stamps 05:00Z with `time_valid` false, which is 00:00 EST, or 01:00 EDT before Nov 1. The tips module flags both as `tip_time_is_placeholder` (feed flag, or any tip at exactly 00:00 ET).

A placeholder proves one thing only: the game is not before 00:00 ET of its game date. So:
- A build before that bound is pre-tip for certain. It is servable but flagged `pre_tip_verified = False`.
- A build after that bound has an unknown tip. It must be refused as "tip time unknown". It must not pass silently, and it must not be labelled "tipped".
- A real tip still in the future must pass, same day included.

On 11-02, 91 of 118 mapped slate games are placeholders. The tip table holds 50 real of 173.

## 3. Tests (`tests/test_tip_guard_placeholder.py`, 10)
- The raw row guard passes a pre-midnight build against a placeholder. This documents why it is not the proof.
- A same-day build (10:00 ET) refuses the placeholder with `TIP_UNKNOWN` and keeps a real 19:00 ET tip. Run with and without the flag column.
- The evening-before build serves the placeholder flagged unverified; the real-tip row is verified.
- A feed-flagged 01:00 EDT placeholder is bounded by 00:00 ET: refused at 00:30 ET, served at 23:30 ET the day before.
- `split_tipped` without a flag column treats midnight as a placeholder.
- Publish flags placeholder rows and labels same-day refusals `tip_time_unknown_placeholder`.
- `stamp_pre_tip_rows` raises for a placeholder row published after its bound.
- `reverify_pre_tip` covers all four statuses.
- The grade stage never grades a `violated` row (pending reason `created_after_real_tip`).

## 4. `data/processed/ingest/tip_times/` (untracked)

- The daily chain consumes ONLY the latest table: the sim / inputs stages via `run_daily_sim_v1.load_slate(tips="table")`, the lines builder via `TIPS`, and now the grade re-check. Nothing reads the snapshot directory.
